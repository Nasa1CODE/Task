# Local Skills and Playbooks

Thư mục này chứa skill/playbook **dùng lại được giữa nhiều dự án**. Không đưa ticket, incident report, schema, endpoint, tên service hay thông tin khách hàng của một dự án cụ thể vào đây.

Mỗi skill mới nên có thư mục riêng với `SKILL.md`, nêu rõ:

1. Mục đích và trigger.
2. Input/output, công cụ được phép dùng.
3. Quy trình kiểm chứng và giới hạn an toàn.
4. Template hoặc tài nguyên đi kèm.

`rules/` là workflow bắt buộc cấp dự án; `skills/` là năng lực bổ sung chỉ gọi khi phù hợp.
